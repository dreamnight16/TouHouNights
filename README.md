# 自动塔防与子弹追踪系统（Tower Defense & Homing Missile）

SAST 游戏开发与设计组免试题 · 程序方向 · **选项二 选项 B**

一个代码生成场景、带本地音乐资源的 Unity 塔防 Demo。工程打开后按下 Play 即可运行，无需手动搭建场景、导入素材或配置任何 UGUI/物理层。

---

## 一、如何运行

1. 用 **Unity Hub** 打开本目录 `TowerDefenseUnity`（已在 **Unity 6.5 / 6000.5.9f1** 上验证，其它 Unity 6.x 也可，若提示升级请选择继续）。
2. 首次打开时 Unity 会自动生成 `Assets/**/*.meta` 与缺失的 `ProjectSettings` 文件，属正常现象，请一并提交。
3. 若 Unity 提示「没有可打开的场景」，直接新建一个空场景（或保持当前空场景）即可 —— 本工程通过 `RuntimeInitializeOnLoadMethod` 自动启动，**场景里不需要放任何东西**。
4. 点击 **Play**，游戏会自动创建相机、地图、正交路线、HUD，各 Stage 自动推进（建造与战斗并行，无需手动开关幕）。

> 若你用的是自带 `SampleScene` 的新建工程，同样直接 Play 即可：脚本会自动把已有相机配置为正交俯视相机。

## 三、题目要求对照

### 门槛要求（必达）

- **敌人与路径**：敌人沿正交路线（只上下左右、贴格子）向基地移动，具备血量、死亡销毁与到达终点逻辑；一波可从多个红门同时出怪 → `Actors/Enemy.cs`、`Systems/MapSystem.cs`、`Systems/WaveSpawner.cs`。
- **索敌与攻击**：防御塔在检测范围内锁定敌人并发射子弹 → `Actors/Tower.cs`、`GameManager.SelectTarget`。
- **子弹命中**：子弹命中后扣血并销毁子弹 → `Actors/Projectile.cs`。

### 进阶挑战（按级别实现）

| 级别 | 挑战 | 实现位置 |
|------|------|----------|
| ★ | 追踪子弹（转向/追踪加速度，实时追踪目标） | `Projectile.Update` 中 `Vector2.MoveTowards` 转向 |
| ★★ | 目标死亡后子弹平滑消失或重新索敌 | `Projectile.TryRetarget` + `BeginFade`（追踪弹就近重锁定，直线弹淡出） |
| ★★★ | 命中产生 AOE 爆炸伤害 | `Projectile.Impact` → `GameManager.DamageEnemiesInRadius` |
| ★★★★ | 至少 2 种防御塔（减速塔 / AOE 塔 / 单体高伤塔） | 5 种塔：机枪（单体快）、狙击（单体高伤）、导弹（追踪+AOE）、减速（范围减速）、治疗（范围回血） |
| ★★★★★ | 智能索敌（血量最低 / 距终点最近 / 距离最近，三选一） | `TargetingPriority` 枚举 + HUD 切换，三种策略全部实现 |

## 五、设计说明（要点）

- **零资源自包含**：所有 Sprite 由 `SpriteFactory` 在运行时用 `Texture2D` 生成，工程无任何外部图片/模型依赖。
- **开放地图 + 正交路线 + 多红门**：3 条贴格子的正交路线（只上下左右），每条一个红门、汇入同一蓝门；一波可同时从多个红门出怪，同一条路线可走不同怪。
- **建造/战斗并行**：各 Stage 由协程自动推进，放塔、撤退、开火与刷怪同时进行，无独立阶段。
- **塔的血量与撤退**：敌人会近战攻击范围内的塔；塔被击毁返还 20%、主动撤退返还 50% 金币。
- **不用物理引擎做命中检测**：敌人与子弹的碰撞按距离在 `Update` 里手动判断，省去 Layer/Tag/Rigidbody 的配置，保证开箱即跑。
- **对象池**：敌人、子弹均走 `ObjectPool`，避免频繁 `Instantiate`/`Destroy` 造成的 GC 抖动。
- **数据驱动**：塔/敌人/Stage 数值集中在 `GameConfig`，便于平衡性调整。
- **全局索敌策略**：三种策略（最近/最低血/最近终点）全部实现并可运行时切换，塔只需调用 `SelectTarget`。
- **空间哈希（ICPC 式优化）**：`SpatialGrid` 用均匀网格把敌人分桶，索敌/AOE/减速的范围查询从 O(N) 全量扫描降为 O(1) 摊销 + 候选集过滤，每帧由 `GameManager` 重建。
- **懒删除堆（ICPC 式优化）**：`MinHeap` 用二叉最小堆维护「血量最低 / 距终点最近」两个全局索引，Pop 时跳过已死敌人（懒删除），塔取目标时「弹死/弹界 + 回插」。
- **BFS 距离场（ICPC 式优化）**：`MapSystem` 把道路格建成 4 邻接无权图，从蓝门 BFS 出每个道路格到基地的最短格数，供「距终点最近」策略 O(1) 查表。
- **UGUI 界面**：`BattleUiRoot` 在运行时构建非对称的战术终端 HUD；左上任务签、上中战况、右上时间、右侧 P 点与右下部署档案彼此独立，让地图保持为视觉主体。中文字体走 `UiFont` 自动探测，失败时回退 legacy Text。
- **结算与评级**：游戏结束弹出结算面板（东方 stage 风格），展示评级大字 + 评分 + 得分/击杀/漏怪/剩余生命/通关 stage；评级按 Phigros 风格映射为 `Φ/V/S/A/B/C`。
- **P点 / 得分 / 弹幕（东方风格）**：击杀累积「得分」与「P点」；P点会线性提升塔伤害（满 +50%）；P点满 1.00 后不再增长，由玩家手动触发「弹幕射击」——从蓝门持续发射范围扫射弹 + 追踪弹，触发后 P点清零。
- **Boss 敌人（结界破壊者）**：最终 Stage V 登场，800 血超大单位、高伤害、移动缓慢、击杀奖励 100 金；出场与击破均有专属横幅预警 + 屏幕震动 + 强化爆炸特效。

### 当前 UI：结界作战档案

- **四角信息岛**：取消贯穿屏幕的上下通栏，左上任务签、上中战况、右上时间、右侧弹幕、右下部署彼此独立。
- **黑白工业排版**：深炭底、纸白反相块、细安全线和编号构成骨架；青色表示操作、黄色表示资源/就绪、红色只用于危险。
- **档案式部署卡**：五张竖卡始终显示费用、键位、职业和可用状态；当前选择通过抬升、底部白轨和文字共同表达，不只依赖颜色。
- **上下文内操作**：塔详情固定在左下，暂停与结算使用专属整屏构图；不改变地图、部署、退款、BOOM、P 点或评分规则。

### 旧版 UI 设计记录（默认入口已停用）

> 以下内容记录此前 `TerminalHud` 方案，便于迁移核对；当前运行时以 `BattleUiRoot` 为准，完整新方案见 [UI_REFACTOR_PROPOSAL.md](UI_REFACTOR_PROPOSAL.md)。

- **延迟伤害血条**：血条分为三层（底轨 / 白色延迟条 / 当前血量条）。受击时当前血量立即下降，白色延迟条稍晚追赶，玩家能直观「看到」每一发造成的伤害量。回血时延迟条立即同步，避免误导。
- **分段式倍速控制**：底栏右侧 4 个独立档位按钮（0.5x / 1x / 2x / 4x），当前档位高亮为 Star 色并加粗描边。相比单一循环按钮，玩家一眼可见所有档位与当前位置。
- **波次进度条**：顶栏结界标签下方细条 + `STAGE n/5` 序号，实时显示当前波次的刷怪进度（已刷出 / 总数）。
- **基地生命条**：顶栏结界数值旁细条显示剩余生命比例；生命 ≤3 时进入 Danger 状态，红色脉动警示。
- **动态安全区**：选中塔时，符卡详情面板会根据该塔在屏幕上的位置自动向左/右滑动避让，避免遮挡玩家关注的战场区域；切换塔时面板平滑滑动跟随。
- **出怪门预警**：换幕时红门光晕快速闪烁 1.2 秒，提示即将出怪。
- **波次清除 / Boss 横幅**：清场时弹出「STAGE CLEAR」；Boss 出场弹出红色预警横幅，击破弹出金色击破横幅。
- **三层爆炸特效**：命中/爆炸由「白闪内核 + 扩散冲击环 + 主体扩散圆」三层组合，冲击感更强。
- **快捷键提示层**：左下角低调半透明提示条，列出 1-5 / Space / X / E / R / Esc 全部快捷键，新手友好。

### 旧版 UI 重构记录：锚点布局 + 设计令牌

用户反馈「上下栏显示不全、中文是方框、看起来还是老样子」。根因诊断：

1. **中文方框**：`Font.CreateDynamicFontFromOSFont("Microsoft YaHei")` 因 YaHei 是 .ttc 集合，Unity 经常静默回退到 Arial（无 CJK 字形）→ TMP 烘焙出的图集不含中文 → 所有中文渲染为方框。修复：`UiFont.cs` 遍历 12 个候选字体，用 `HasCharacter('中')` 逐一验证，通过后才创建 2048² 动态 TMP 资产。
2. **上下栏显示不全**：旧代码使用「相对 1280×720 参考分辨率的绝对 x」，但 `CanvasScaler matchWidthOrHeight=0.5` 会让实际画布宽度偏离 1280，那些坐标就被推出屏幕。修复：新增 `TdLayout.Band` + `InLeft` / `InRight` / `InCenter` 锚点原语，子元素只描述「相对父节点的位置」，几何上不可能溢出画布。
3. **看起来还是老样子**：之前的修改只是换色，结构、尺寸、位置全没变。修复：从零重写 `HudTopBar` / `HudDeployBar` / `HudUnitCard` / `HudEnemyInspector` / `HudFeedback` / `TerminalHud`，全新配色、全新卡面层次、左侧职业色脊线、居中锚点横幅。

### 旧版 UI 架构：Flat Spatial 三层结构

原先的 HUD 是 1200+ 行的单体类，所有读数平铺在一屏。重构后拆成「一个装配器 + 五个专注组件」：

| 层 | 组件 | 只回答一个问题 |
|---|---|---|
| ① 战局状态层（顶） | `HudTopBar` | 这一局现在怎么样 |
| ② 战场空间层（中） | `HudRangeIndicator` + `TowerPlacer` | 我在哪、能打到哪 |
| ③ 快速操作层（底） | `HudDeployBar` | 我现在能部署什么 |
| 按需信息 | `HudUnitCard` / `HudEnemyInspector` | 我关注的那一个是谁 |
| 纯反馈 | `HudFeedback` | 现在发生了什么 |

关键改动：

- **渐进式披露（Progressive Disclosure）**：信息不是消失，而是按玩家当前任务出现。部署卡默认只有「职业图标 + 费用」，名称在悬停/选中时才淡入；敌人默认只有一条血条，把指针放到它身上才展开详细卡；单位卡只在选中符卡时存在。
- **状态可视化优先于数值**：弹幕技能不再显示「冷却 3.2 秒」，而是 P 点环充满 + 图标由 `P` 变 `✦`；技能就绪是「亮起来」，不是「数字归零」。
- **信息贴近主体**：单位卡 / 敌影卡都锚定在世界坐标旁，用一条细引导线连回单位，而不是弹一个居中面板打断视线。
- **干净的几何范围**：攻击范围从「每格一张半透明圆角方块」改成「整体淡蒙版 + 四条边界线 + 四角 L 型角标 + 极淡格线」，边界成为视觉主体，格子越多也不糊。
- **语义化颜色**：`TdTheme.Sem` 统一定义 白=信息 / 灰=不可用 / 蓝=可操作 / 黄=注意 / 红=危险 / 绿=成功，组件一律引用令牌，不再写死色值。
- **动效有目的**：动效时长统一在 0.15~0.4s（`TdTheme.Motion`），只在状态真的变化时动 —— 结界 ≤3 才脉动、Boss 出场才闪屏、范围角标才呼吸。
- **Design System 令牌层**：间距走 8pt 栅格（`TdTheme.Space`）、圆角收敛到 0/4/6/10 四档（`TdTheme.Radius`）、布局原语集中在 `TdLayout`（含世界锚定换算与「贴身面板」自动左右翻转 + 安全区夹取）。
- **极端比例保护**：顶栏和底栏卡牌组都加了 `FitContent()` / `FitCardGroup()` —— 画布过窄时整层等比收缩，常规 16:9 下系数恒为 1，看不出任何变化。

> 此次重构只改表现层：核心玩法、数值与世界设定（结界 / 灵力 / 敌影 / 符卡 / P 点 / 弹幕 / 时之流速）完全未动。

### 世界层视觉重构：WorldArt 设计系统

HUD 有了 `TdTheme`，但战场里仍然是「每个文件各写各的色值和尺寸」—— 深色叠深色、球圆方随意混搭。新增 `Core/WorldArt.cs` 作为世界层的单一真相，并定下三条硬规则：

| 规则 | 内容 |
|---|---|
| **明度阶梯** | 虚空 4% → 棋盘 8% → 网格 12% → 路径 18% → 建筑 30% → 单位 55%~85%。相邻层必须拉开明度，禁止「深色上叠深色」 |
| **统一描边** | 任何单位先铺一层放大 1.16 倍的近黑剪影，再叠本体色，保证能从背景里「剥」出来 |
| **统一打光** | 光来自左上 45°，一律「顶部缩小 + 上移 + 提亮」配合压扁的落地投影 |

**形状即信息**（新增 `SpriteFactory` 图元）：六边形 = 平台/建筑，箭形 = 有朝向的机动单位，菱形 = 尖锐/精准职业，圆环 = 范围/光环，L 角标 = 取景与锁定。同一剪影贴图被描边/本体/高光三层复用，只靠 `renderer.color` 相乘改明度，不额外产生贴图。

| 单位 | 剪影 | 玩家一眼读到的 |
|---|---|---|
| 塔 · 机枪 / 狙击 / 导弹 / 减速 / 治疗 | 箭 / 细长菱形 / 六边形 / 正菱形 / 六边形+十字 | 不看颜色也能分辨职业 |
| 敌人 · 普通 / 高速 / 重甲 / Boss | 箭 / 细箭 / 宽六边形 / 巨箭 + 威胁环 | 体型与朝向即威胁等级 |
| 弹丸 | 沿飞行方向拉长的菱形 | 弹道朝向可见 |

其他：

- **连续路面**：路径不再是「一格一块圆角方砖 + 中间虚线」，而是整段连续的路面 + 描边 + 沿行进方向的小箭头，转角天然无缝。
- **朝向即状态**：敌人与弹丸都朝行进方向平滑转向，炮塔整组转向目标 —— 动效传递信息而不是装饰。
- **棋盘取景框**：可部署区域有明确的底板、四条边线与四角 L 型准星，出怪门有指向首段路线的箭头，基地是缓慢自转的双层环 + 六边形核心。
- **渲染层序分区**：`WorldArt.Layer*` 把层号按职能分段（地面 −10 / 地图与建筑 0~9 / 敌人 12~17 / 弹丸 18~19 / 血条 20~22 / 爆发 30~32），避免同层并列导致的遮挡不确定。
- **配色方向**：深蓝灰打底（不是纯黑）+ 天蓝为我方 + 珊瑚红为敌方 + 琥珀点缀，清新但不失科技感。

> 同样只改表现层：`MapSystem` 的道路格集合与 BFS 距离场、`GameConfig` 的路线/费用/血量/刷怪表全部原样保留。
